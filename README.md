## 📌 Описание проекта
Приложение представляет собой десктопный программный комплекс с графическим интерфейсом для решения широкого спектра задач вычислительной математики. Основной упор в проекте сделан на **экстремальную производительность расчетов** при работе с тяжелыми математическими алгоритмами.

### Реализованный функционал (Вычислительные модули):
* **Численное интегрирование:** Реализация классических методов для расчета определенных интегралов.
* **Решение дифференциальных уравнений:** Моделирование динамических систем численные методами.
* **Работа с полиномами:** Алгоритмы вычисления, сложения, умножения и поиска корней многочленов.
* **Аппроксимация функций:** Сглаживание и построение приближающих функций на основе дискретных наборов данных (например, метод наименьших квадратов).
* **Решение нелинейных уравнений:** Быстрый поиск корней сложных нелинейных систем и одиночных уравнений.

---

## 🛠 Технологический стек
* **Язык программирования:** Python
* **Вычислительное ядро:** NumPy*
* **Ускорение расчетов:** Numba*
* **Графический интерфейс:** PyQt6*.

---

## 💎 В чем главная ценность кода
* **High-Performance Computing:** Код демонстрирует навыки оптимизации производительности. Использование декораторов `@jit` / `@njit` из библиотеки Numba позволяет выполнять сложные математические циклы (интегрирование, дифуры) с околонулевыми накладными расходами Python.
* **Разделение логики:** Вычислительные тяжелые алгоритмы (математическое ядро) строго отделены от интерфейсной части на PyQt, что делает архитектуру чистой.
