Программная обеспечения «Инженерные вычисления»

Интерактивное приложение для численного анализа и моделирования на языке Python

О программе

ПО «Инженерные вычисления» представляет собой настольное приложение, разработанное для решения прикладных математических и инженерных задач численными методами. Программа сочетает в себе математическое ядро с оптимизированными алгоритмами и графический интерфейс пользователя, обеспечивающий удобный ввод параметров, автоматическую валидацию данных и визуализацию результатов.

Функциональные модули

1. Численное интегрирование

Расчет определенных интегралов методами левых, правых и средних прямоугольников, трапеций и Симпсона. Реализована оценка погрешности по правилу Рунге.

2. Нелинейные уравнения

Нахождение корней уравнений в диалоговом режиме с помощью пяти методов: дихотомии, хорд, касательных (Ньютона), комбинированного метода и метода простых итераций.

3. Интерполяция

Построение интерполяционных полиномов в канонической форме, а также по формулам Лагранжа и Ньютона. Автоматический расчет коэффициентов по заданным узлам.

4. Аппроксимация (МНК)

Сглаживание табличных данных методом наименьших квадратов. Доступны линейная, параболическая (квадратичная) и пользовательская модели регрессии.

5. Решение краевых задач

Численное решение дифференциальных уравнений 2-го порядка методом конечных разностей. Поддерживается решение разностных систем методом прогонки, Гаусса, Крамера и матричным методом.

Архитектурные и технические особенности

  • Структурированная модульная архитектура: Исходный код четко разделен по зонам ответственности. Пользовательский интерфейс (папка Window), вспомогательные компоненты (Components), логика валидации данных (Validation) и математические расчеты (Calculate) изолированы друг от друга.
  • Высокая производительность (JIT-компиляция): Ресурсоемкие итерационные циклы и расчеты погрешностей оптимизированы с помощью компилятора Numba (декоратор @njit), что предотвращает зависание графической оболочки PyQt6 при больших объемах данных.
  • Многоуровневая превентивная валидация: Система в реальном времени проверяет корректность вводимых данных (диапазоны ОДЗ, равенство шага нулю, дублирование узлов интерполяции по оси абсцисс), блокируя выполнение некорректных расчетов.
  • Интерактивная визуализация: Построение графиков решений, экспериментальных точек и аппроксимирующих кривых осуществляется динамически с помощью библиотеки Matplotlib.
